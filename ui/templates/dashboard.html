The 4 Documented Port & Service Checks Architecture

Rigorous modular inspection pipeline conforming to AIORI-3 PS-011 and OWASP WSTG

1 TCP State & Latency Probe

Full 3-way handshake via non-blocking socket.connect_ex (RFC 793). Classifies ports into OPEN, CLOSED, or FILTERED while measuring round-trip latency in milliseconds.

2 Banner Grab & Fingerprint

Passive reading followed by safe initial probes to capture service greetings (SSH, SMTP, FTP, Redis, MySQL). Regex heuristics identify software version and daemon identity.

3 TLS Handshake & Ciphers

SNI-enabled TLS negotiation extracting negotiated protocol (TLSv1.2/1.3), cipher suite, and DER X.509 certificate. Computes days-to-expiry and identifies expired certificates.

4 Application HTTP/HTTPS

Safe HTTP GET probe with custom authorized user-agent. Evaluates status code, HTML <title>, Server banner, tech stack signatures, and defensive headers (HSTS, CSP).
